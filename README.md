# 소방시설 적용·안전관리 검토 시스템 v2.8 (구 HFLS)

건축허가등 **신청(신고)일**을 기준으로 당시 시행령 별표(소방시설 설치기준)를 판정하고,
**부칙 소급 · 강화기준 특례(법 제13조) · 증축·용도변경 특례(시행령 제15조)** 와 **현행 기준**을 함께 비교하는 업무 참고용 웹앱입니다.

> 현행 기준: 「소방시설 설치 및 관리에 관한 법률 시행령」 대통령령 제36728호(2026.10.2. 시행), 별표4 <개정 2025.11.25.>

## v2.7.1 변경사항 (2026-11-06)

## v2.7 변경사항 (2026-11-06) — 사용 횟수·오류 신고
- 머리말에 **오늘 · 누적 사용 횟수** 표시(접속 기준, 같은 탭 새로고침은 1회, 한국시간 자정 기준 일자 구분).

- 관리자 모드 「오류 신고함」: 목록·첨부 보기·**입력값 불러오기**(신고 당시 화면 재현)·삭제.
- 서버: `api/stats.js`, `api/report.js` (Vercel 함수) + Upstash Redis. 저장소를 연결하기 전에는 횟수가 표시되지 않고, 신고 창은 「내용 복사」로 대체됨.
- 남용 방지: 방문 IP당 하루 200회, 신고 IP당 1시간 10건, 신고 최근 2,000건 보관.

### 사용 통계·오류 신고 설정 (1회)
1. Vercel 프로젝트 → **Storage** 탭 → **Create Database** → **Upstash for Redis**(Marketplace) → 무료 플랜 → 이 프로젝트에 연결.
   - 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 자동으로 들어갑니다.
2. Vercel 프로젝트 → **Settings → Environment Variables** → `ADMIN_PW` 추가(관리자 비밀번호, 서버에서만 확인 — 화면 코드에 들어가지 않음).
   - 설정 후 관리자 버튼은 이 비밀번호로 열리고, 오류 신고함도 이 비밀번호로만 열립니다.
   - `REACT_APP_ADMIN_PW`는 더 이상 필요 없습니다(설정했다면 삭제 권장 — 화면 코드에 노출됨).
3. **Redeploy** → 머리말에 「오늘 1 · 누적 1」이 보이면 완료.

## 1. GitHub·Vercel 반영 방법 (기존 hfls 저장소 덮어쓰기)

1. 기존 저장소에서 **`src/data.js` 삭제** (v2에서는 `src/law/` 폴더로 대체)
2. 이 압축파일의 내용을 저장소 루트에 그대로 업로드(덮어쓰기)
   - `package.json`, `package-lock.json`, `capacitor.config.json`, `public/`, `src/`, `scripts/`, `assets/`, `.github/`, `README.md`, `.gitignore`
   - 웹 업로드 시 `.github` 폴더가 숨김 처리되어 빠지지 않도록 확인(GitHub Desktop 사용 권장)
3. 커밋 → Vercel이 자동 재배포 (프레임워크: Create React App, 빌드 `npm run build`, 출력 `build`)
4. (선택) 관리자 비밀번호 변경: Vercel → Project → Settings → Environment Variables 에
   `REACT_APP_ADMIN_PW` 추가 후 재배포. 미설정 시 기존 값(3535) 사용.
   ※ 클라이언트 측 잠금이므로 보안 수단이 아닙니다.

