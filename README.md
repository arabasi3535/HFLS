# 소방시설 적용·안전관리 검토 시스템 v2.21 (구 HFLS)

건축허가등 **신청(신고)일**을 기준으로 당시 시행령 별표(소방시설 설치기준)를 판정하고,
**부칙 소급 · 강화기준 특례(법 제13조) · 증축·용도변경 특례(시행령 제15조)** 와 **현행 기준**을 함께 비교하는 업무 참고용 웹앱입니다.

> 현행 기준: 「소방시설 설치 및 관리에 관한 법률 시행령」 대통령령 제36728호(2026.10.2. 시행), 별표4 <개정 2025.11.25.>

> 버전 규칙: 큰 기능 추가는 가운데 번호(2.**11**.0), 세부 수정은 끝 번호(2.11.**2**)를 올립니다.
