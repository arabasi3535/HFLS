# HFLS v2.2 — 소방시설 연혁 법령 적용 지원 시스템

건축허가등 **신청(신고)일**을 기준으로 당시 시행령 별표(소방시설 설치기준)를 판정하고,
**부칙 소급 · 강화기준 특례(법 제13조) · 증축·용도변경 특례(시행령 제15조)** 와 **현행 기준**을 함께 비교하는 업무 참고용 웹앱입니다.

> 현행 기준: 「소방시설 설치 및 관리에 관한 법률 시행령」 대통령령 제36728호(2026.10.2. 시행), 별표4 <개정 2025.11.25.>

## v2.2 변경사항 (2026-11-04)
- **소방법 시대(1992.7.28.~2004.5.29.) 판정 추가** — 소방특별조사 운영매뉴얼 제5장 「소방시설의 연도별 적용기준」 반영(검증등급 `M` 매뉴얼확인). 1992.7.28. 이전만 미수록.
- **2004~2015 기준 정정** — 아파트 SPK(16층 이상의 층 → 2005.1.1. 11층 이상), 정신의료기관·요양병원 자탐·속보(2014/2015.7.1.), 노유자 간이SPK(2008.8.16.), 터널 연결송수관(2,000m→1,000m→500m) 등.
- **증축 60분 방화문** — 시행령 제15조제1항제2호나목 「60분+ 방화문 또는 60분 방화문」(2025.12.1. 시행), 부칙(대통령령 제35860호) 제3조에 따라 2022.12.1. 이후 증축 신청분 소급. 2022.12.1. 전 신청분은 구 갑종방화문 기준으로 구획 인정하되 확인 필요 표시.
- **노유자 생활시설(v2.2.1)** — 2012.2.5. 시행 개정으로 도입된 구분이므로 그 전 기준일은 모두 '노유자시설'(면적 기준)로 판정. 재가노인복지시설(주·야간보호·단기보호)은 노유자 생활시설(시행령 제7조제1항제7호가목1)로 분류. 2013.2.10. 이후 가목2)·나목~바목 시설이 단독·공동주택에 설치된 경우 생활시설에서 제외(입력 체크).
- **v2.2.2 상식 점검 보정** — 단독주택은 별표2 특정소방대상물이 아니므로 별표4 판정 제외(주택용소방시설만). 층별 면적 미입력 층은 '연면적 − 입력 층 합'을 상한으로, 수용인원 미입력은 별표7 제2호(÷1.9㎡) 상한으로 판정해 불필요한 [확인 필요] 제거. 대규모점포 3,000㎡ 미만 입력 경고.
- **v2.2.3 자체 검증(32건)** — `src/law/verify/cases30.js` 사례를 법령 원문·운영매뉴얼 기준 기대값과 대조(`npm test`에 포함). 수정: 옥내소화전 2) 용도에 국방·군사시설 포함·교정시설 제외, 2004~2022 업무·공장·창고 자동화재속보설비 '야간 무인경비' 요건 반영, 24시간 상주 시 속보설비 단서 안내, 연립·다세대(2024.12.1. 전) 결과 불필요 하향 제거.
- **v2.2.4 화면 단순화** — 일반 사용자에게는 「적용 검토」「사용 안내」 탭만 표시. 「법령 연혁」「규칙·검증현황」은 관리자 모드에서만 표시.
- **버전 표시** — 머리말 배지·바닥글에 `v버전 · 빌드시각(KST) · 커밋해시` 표시(`scripts/build-info.js`가 빌드 때 자동 생성). 배포 후 이 값이 바뀌었으면 반영된 것입니다.

## 1. GitHub·Vercel 반영 방법 (기존 hfls 저장소 덮어쓰기)

1. 기존 저장소에서 **`src/data.js` 삭제** (v2에서는 `src/law/` 폴더로 대체)
2. 이 압축파일의 내용을 저장소 루트에 그대로 업로드(덮어쓰기)
   - `package.json`, `package-lock.json`, `capacitor.config.json`, `public/`, `src/`, `scripts/`, `assets/`, `.github/`, `README.md`, `.gitignore`
   - 웹 업로드 시 `.github` 폴더가 숨김 처리되어 빠지지 않도록 확인(GitHub Desktop 사용 권장)
3. 커밋 → Vercel이 자동 재배포 (프레임워크: Create React App, 빌드 `npm run build`, 출력 `build`)
4. (선택) 관리자 비밀번호 변경: Vercel → Project → Settings → Environment Variables 에
   `REACT_APP_ADMIN_PW` 추가 후 재배포. 미설정 시 기존 값(3535) 사용.
   ※ 클라이언트 측 잠금이므로 보안 수단이 아닙니다.

로컬 실행
```bash
npm install
npm start          # http://localhost:3000
npm test           # 판정 엔진 단위테스트(66건: 판정 엔진 34 + 검증사례 32)
npm run build      # 배포용 빌드 (CI=true 에서도 경고 없이 통과 확인)
```

## 1-1. 휴대폰 앱으로 쓰기

### (A) 안드로이드 APK — GitHub가 자동으로 만들어 줌
1. 이 폴더 전체(숨김 폴더 `.github` 포함)를 저장소에 올리고 커밋
2. 저장소 상단 **Actions** 탭 → `Android APK` 실행 확인(약 5~10분, 초록 체크)
3. 저장소 첫 화면 오른쪽 **Releases** → 최신 `HFLS 안드로이드 앱` → `HFLS-번호.apk` 를 **휴대폰으로** 내려받기
4. 설치 시 "출처를 알 수 없는 앱 설치 허용" 승인 → 설치
- 이후 커밋할 때마다 새 APK가 자동 생성됩니다(앱 안에 판정 데이터가 포함되어 오프라인 동작).
- 비공개 저장소면 휴대폰에서 GitHub 로그인 후 내려받으십시오.

**서명키 설정(권장, 1회)** — 설정하지 않으면 매번 다른 디버그 키로 서명되어 새 버전 설치 시 기존 앱을 지우고 다시 설치해야 합니다.
저장소 → Settings → Secrets and variables → Actions → New repository secret
- `HFLS_KEYSTORE_BASE64` = 별도 전달된 `hfls-keystore-base64.txt` 내용 전체
- `HFLS_KEYSTORE_PASSWORD` = 별도 전달된 비밀번호
- 키 파일(`.jks`)·비밀번호는 저장소에 올리지 말고 따로 보관(분실 시 업데이트 설치 불가)

### (B) PWA — 파일 없이 사이트에서 설치
- 안드로이드 크롬: hfls.vercel.app 접속 → 메뉴 → "앱 설치/홈 화면에 추가"
- 아이폰 사파리: 공유 → "홈 화면에 추가"
- 최초 접속 후 오프라인 실행 가능(서비스워커 `public/sw.js`)

## 3. 데이터 구조

```
src/
├── App.js                    # 화면 구성(탭: 적용 검토 / 법령 연혁 / 규칙·검증현황 / 사용 안내)
├── styles.css
├── components/
│   ├── InputPanel.js         # 기준시점·용도·규모·층별면적·세부조건 입력
│   ├── ResultView.js         # 결론·검토표·부칙소급·확인필요·CSV/인쇄
│   └── InfoTabs.js           # 연혁·규칙 데이터(관리자 검증메모)·안내
└── law/
    ├── sources.js            # 법령 체계·개정 연혁·원문 출처·주요 일자
    ├── uses.js               # 별표2 용도 분류
    ├── facilities.js         # 소방시설 30종(현행 별표4 호·목, NFTC 번호), 별표5 면제 안내
    ├── criteria.js           # ★ 판정 규칙(효력구간·검증등급·근거)
    ├── retro.js              # 부칙 소급·법 제13조·주택용소방시설·제15조 특례
    ├── logic.js              # 3값 논리·층별 파생값·입력 불일치 점검
    ├── engine.js             # 판정 엔진·종합검토·CSV
    └── engine.test.js        # 단위테스트
```

### 규칙 추가·수정 예 (`src/law/criteria.js`)
```js
{
  id: "spk-6f", fac: "spk",
  from: "2017-01-28", to: "9999-12-31",   // 효력구간 [from, to)
  // fromU: ["2004-05-30","2020-12-10"],  // 도입시점이 이 사이(불명확)일 때
  cert: "V",                                // V 원문확인 / M 매뉴얼확인 / I 시점추정 / U 미검증
  src: "s2,cur4,reasons", cur: "1)",
  text: "층수 6층 이상 (모든 층)", scope: "모든 층",
  when: (c) => ge(c.x.gf, 6),               // true/false/null(입력부족)
  basis: (c) => `지상 ${c.x.gf}층`,
}
```
